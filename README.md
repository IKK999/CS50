# Parser AI (NLP Syntax Tree Generator)

A natural language processing system that parses sentences into **syntactic structures** using a **Context-Free Grammar (CFG)** and extracts meaningful linguistic components.

---

## Overview
This project analyzes input sentences and generates **parse trees** that represent grammatical structure. It also extracts **noun phrase (NP) chunks**, a key step in many NLP pipelines.

It includes:
- Custom CFG-based grammar definition  
- Sentence preprocessing and tokenization  
- Chart parsing for syntactic analysis  
- Noun phrase chunk extraction  

---

## Features
- **Context-Free Grammar (CFG)** for language modeling  
- **Chart parser (NLTK)** for efficient parsing  
- **Custom preprocessing pipeline**
  - Lowercasing  
  - Tokenization  
  - Noise filtering  
- **Noun Phrase (NP) chunk extraction**  
- **Parse tree visualization**  

---

## Tech Stack
- Python 3.x  
- NLTK (Natural Language Toolkit)
