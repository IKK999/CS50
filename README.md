# Tic-Tac-Toe AI (Minimax Engine)

A game-playing AI that solves Tic-Tac-Toe optimally using the Minimax algorithm, demonstrating adversarial search, recursion, and decision-making under perfect information.

---

## Overview

- This project implements a complete Tic-Tac-Toe system where:
- Two players compete in a zero-sum game
- The AI evaluates all possible future states
- The optimal move is selected via Minimax search
- The result is an AI that cannot be beaten.

---

## Features
- Minimax algorithm implementation
- Exhaustive game tree search for optimal decision-making
- Adversarial reasoning
- Models competitive environments with opposing objectives
- State-space exploration
- Recursively evaluates future board configurations
- Game engine logic
- Handles turns, legal moves, terminal states, and scoring
- Interactive GUI (Pygame)
- Play against the AI in real time

---

## Tech Stack
- Python 3.x
- Pygame
- Core concepts: Minimax, recursion, game theory
