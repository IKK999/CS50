# Knights AI (Logical Reasoning Engine)

A symbolic AI system that solves **Knights and Knaves logic puzzles** using **propositional logic and model checking**, demonstrating formal reasoning and knowledge-based inference.

---

## Overview
This project models classic logic puzzles where:
- **Knights always tell the truth**
- **Knaves always lie**

The system encodes statements as logical expressions and determines which propositions are **logically entailed** by a knowledge base.

---

## Features
- **Custom propositional logic engine**
  - Symbols, AND, OR, NOT, Implication, Biconditional  
- **Model checking algorithm**
  - Exhaustively evaluates all possible truth assignments  
- **Knowledge base construction** for complex puzzles  
- **Automated logical inference** (entailment detection)  

---

## Tech Stack
- Python 3.x  
- Standard library only
