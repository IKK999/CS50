# Heredity AI (Bayesian Inference Engine)

A probabilistic inference system that models **genetic inheritance and trait expression** using joint probability distributions. This project applies core concepts from **Bayesian networks, combinatorics, and statistical inference** to compute the likelihood of genes and traits across a family tree.

---

## Overview
This system analyzes hereditary data and computes the probability that each individual:
- Has **0, 1, or 2 copies of a gene**
- Exhibits a given **trait**

It accounts for:
- Parental inheritance
- Mutation rates
- Conditional trait probabilities

---

## Features
- **Full joint probability computation** across all possible gene/trait combinations  
- **Bayesian reasoning** with conditional probabilities  
- **Support for incomplete data** (unknown traits)  
- **Automatic normalization** of probability distributions  
- **Accurate modeling of mutation and inheritance dynamics**
