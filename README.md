# Nim AI (Reinforcement Learning Agent)

A reinforcement learning system that learns to play the game of **Nim** using **Q-learning**, demonstrating core concepts in **decision-making, exploration vs. exploitation, and value iteration**.

---

## Overview
This project trains an AI agent through **self-play** to discover optimal strategies in a combinatorial game environment.

It includes:
- A full game engine for Nim  
- A **Q-learning agent** with epsilon-greedy policy  
- Training via repeated simulation  
- Human vs AI gameplay interface  

---

## Features
- **Q-learning implementation from scratch**  
- **Epsilon-greedy strategy** for exploration vs exploitation  
- **State-action value function (Q-table)**  
- **Self-play training loop** with reward signals  
- **Interactive gameplay vs trained AI**  

---

## Tech Stack
- Python 3.x  
- Standard library only (no external ML frameworks)
