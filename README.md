# Minesweeper AI (Knowledge-Based Agent)

An intelligent agent that plays Minesweeper using **logical inference and knowledge representation**, demonstrating core principles of **symbolic AI and constraint reasoning**.

---

## Overview
This project builds an AI that plays Minesweeper by **reasoning about uncertainty** rather than guessing blindly.

It includes:
- A full game engine  
- A **knowledge-based AI agent**  
- Logical inference using propositional constraints  
- Interactive gameplay with optional AI assistance  

---

## Features
- **Knowledge-based reasoning system**
  - Sentences representing constraints (cells = mine counts)  
- **Inference engine**
  - Identifies safe cells and mines  
  - Derives new knowledge from existing facts  
- **Safe vs random move strategy**
- **Dynamic knowledge base updates**  
- **Interactive UI with AI integration (Pygame)**  

---

## Tech Stack
- Python 3.x  
- Pygame (UI)  
- Standard library
