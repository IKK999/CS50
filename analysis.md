# Analysis

## Layer TODO, Head TODO

Each word pays attention to the previous word. Since [MASK] in each case serves a grammatical purpose, the order of words seem to be very important. 

Example Sentences:
- I know that this [MASK] wrong
- Why should I go out [MASK] my way to do this

## Layer TODO, Head TODO

Words pay attention to each other in a somewhat equal manner. Since [MASK] in each case can be any verb, the context derived from all other words seem to be important. 

Example Sentences:
- My grandson [MASK] it
- I should [MASK] every morning
